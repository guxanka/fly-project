# Fly_project — рекламный лендинг сервиса путешествий

Одностраничный рекламный сайт (landing page) для вымышленного сервиса поиска авиабилетов. Проект демонстрирует продуктовый маркетинговый лендинг с акцентом на конверсию в установку приложения и переходы в социальные сети. [ссылка на сайт](https://guxanka.github.io/fly-project/)

## О проекте

Сайт создан как лендинг-визитка сервиса: рассказывает о преимуществах использования продукта, объясняет принцип работы и мотивирует пользователя перейти в приложение или подписаться на соцсети бренда. Упор сделан на нестандартный визуальный стиль, разговорный tone of voice и анимационные акценты, повышающие вовлечённость.

## Функционал

**Пользовательская часть:**
- Приветственный экран с анимированным фоном (blob-анимации)
- Блок преимуществ сервиса
- Пошаговое объяснение принципа работы
- Cтатистика (счётчики)
- Блок с мокапом приложения и кнопками перехода в App Store / Google Play
- Секция с переходами в социальные сети (Instagram, Telegram, ВКонтакте, YouTube)
- Адаптивная вёрстка под мобильные устройства
- Плавный скролл по навигационному меню

## Стек

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Анимации:** CSS keyframes, Intersection Observer API
- **Сервер:** не требуется — статический сайт

## Особенности реализации

- Адаптивная сетка карточек (`grid-template-columns: repeat(auto-fit, minmax(...))`) без медиазапросов для десктопа.
- Цветовая палитра подобрана с акцентом на запоминаемость: фиолетовый, кислотно-жёлтый, коралловый, бирюзовый.
